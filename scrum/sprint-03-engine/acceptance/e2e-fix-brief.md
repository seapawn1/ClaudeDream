## 修复项 1：M2 孤儿判据误杀健康记忆（判据口径错误）

**现象**（主库 45 条记忆考场，PO 亲见报告）：

- 一场梦隔离 30 条，理由全部为 `M2-orphan`；其中约 26 条是健康记忆——它们只是互相没有链接（独立无链是健康记忆的常态，不是腐烂）。
- `report-only` 档场隔离 31 条。
- 连锁伤害：某条 M4 确凿死实体（git 史有讣告，按 AC 应删除）被 M2 抢先隔离，确凿删除票未执行。

**根因**：M2 把「无出链且无入链」直接判为 orphan 并隔离。判据默认方向错了：无链 ≠ 腐烂。

**修复要求（行为级）**：

1. **健康记忆零误报**：无链但无其他腐烂特征的记忆不得被隔离（02.2-AC7）。
2. **真孤儿仍要检出**（02.2-AC2 不能丢）。
3. **判据叠加时正确处置**：同一记忆同时命中 M2（无链）与 M4 确凿（有讣告）时，确凿删除票必须执行，M2 不得抢先隔离、吞掉更高优先级的处置动作。
4. feedback 类豁免现状保持不变（已验证为真，别碰）。

**方向参考**（实现归你们）：孤儿判定可收窄（如要求无链且无其他存在性证据），或 M2 默认降为报告级提示、只有更强证据才隔离。具体口径你们定，上述行为级要求必须满足。

**验证**：你们 D1 自证 + PO 端到端复验。复验口径：健康记忆零隔离；真孤儿仍检出；确凿删除票执行。

## 修复项 2：熔断回滚在 Windows 失败（实现 bug）

**现象**（熔断专用库，PO 亲见报告与现场）：

- 正式场熔断正确触发（净消失 4 > max(3, 1)，当场中止、未提交——**这部分是对的，别动**）。
- 回滚命令 `git checkout <preSha> -- D:\...\breaker-yard\.claude\memory D:\...\breaker-yard\CLAUDE.md` 报错：`error: pathspec 'D:\...\CLAUDE.md' did not match any file(s) known to git`。
- 结果：4 个删除 + 2 个隔离标记全部留在工作树，记忆未回梦前状态。
- 报告如实自曝「⚠️⚠️ 回滚失败……请立即人工核对（不得依赖自动回滚）」——**这个诚实披露行为保留**。

**根因**：回滚 pathspec 用了仓库根**绝对路径**（Windows 反斜杠形式），git 拒绝；且未入库的 CLAUDE.md 也被放进 pathspec，一条不匹配导致整条命令失败。

**修复要求（行为级）**：

1. 回滚命令在仓库 cwd 内执行，pathspec 一律使用**仓库内相对路径**（如 `.claude/memory`）。
2. CLAUDE.md 未入库（untracked）时不得进入回滚 pathspec——要么剔除、要么单独判断。
3. 熔断后工作树必须回到梦前状态：`git status --short` 为空、记忆文件数与内容与梦前一致。
4. 回滚失败时报告如实自曝的行为保留（修复后正常路径应成功）。

**验证**：Windows 上重演熔断场景（熔断专用库），熔断后 `git status --short` 为空、记忆文件数复原。

## 修复项 3：CLI 直跑路径冷却与 last-dream 缺席（PO 裁定的设计变更）

**现象**（PO 亲见）：

- 熔断后立刻重跑 CLI 梦，畅通无阻（又删 1 条）——CLI 直跑不设冷却。
- CLI 跑完不落 `.claude/dream/last-dream.json`——G9 检索无基线，退化为全收模式（旧页重复引用）。

**PO 裁定**：CLI 直跑路径也要有冷却与 last-dream 状态。原「CLI 是显式人工调用、不受闸门约束」的边界就此调整。

**修复要求（行为级）**：

1. CLI 直跑 `run-dream.mjs` 落 `last-dream.json`：status（running/completed/failed/fused）+ 顶层 `runId` + `lastDreamAt`，形态按 adapter.json 声明。
2. CLI 直跑受冷却约束：冷却期内再跑被拦下（提示剩余冷却时间）；`cooldown_minutes=0` 的环境变量覆盖通道保持可用（连续运行/考试需要）。
3. 熔断终态（fused）冷却照常起算（熔断算做过一场梦）。
4. G9 基线恢复窗口语义：`last-dream.json` 有 `runId` 时按「上次梦 runId 之后」过滤底片页；无 last-dream（历史/异常）时保守全收的现行为保留。
5. `enabled` 闸门语义不变：CLI 直跑仍不受 `enabled=false` 约束（那是自动链路闸门，不是本项范围）。

**验证**：CLI 跑一场 → 立刻重跑被冷却拦；env `cooldown_minutes=0` → 重跑放行；`last-dream.json` 落盘且 `runId` 随场递增；G9 在多页底片时只收基线之后的页。

## 边界：不得破坏已验证为真的行为

以下行为 PO 亲验为真，修复时不得回退：

- 报告六节结构、明细四要素、执行日志证据、死者遗言、抽查点（站 3 全绿）。
- feedback 保护铁律：字节零改动、只进「待你裁决」（站 2 实测）。
- 隔离标记形态与可逆性：去标记即逐字节还原（站 2 实测）。
- M4 两级证据区分（确凿/候选）、熔断中止与计数口径（净消失数＝删除笔数，隔离与索引修复不混入）。
- 报告诚实自曝（熔断回滚失败、阀门环境变量覆盖均如实写）。
- 零 API：无登录态环境整梦跑通。
