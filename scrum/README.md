## 从设计冲刺到 Scrum 的交接

设计冲刺回答的是"造什么、为什么这么造"，Scrum 回答的是"现在开始造，怎么排、怎么验"。交接的实物是：

- **入场条件**——[.IDEO/design-sprint/Target-1-Consolidation/Prototype-01-FirstDream/verdict.md](.IDEO/design-sprint/Target-1-Consolidation/Prototype-01-FirstDream/verdict.md) §3 的 C1–C7 七条改造，已转写进 [ProductBacklog.md](ProductBacklog.md) 的 Definition of Output Done（Q1–Q7）与 Backlog 骨架（B4/B5）
- **设计结论**——去 [.IDEO/design-sprint/DesignReview.md](.IDEO/design-sprint/DesignReview.md) 读，不在本目录重复
- **方案内部结构**——去 [Architecture.md](Architecture.md) 看图，细节回 [.IDEO/design-sprint/Target-1-Consolidation/Prototype-01-FirstDream/Sketches.md](.IDEO/design-sprint/Target-1-Consolidation/Prototype-01-FirstDream/Sketches.md) 查
