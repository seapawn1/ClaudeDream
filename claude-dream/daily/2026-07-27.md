**ClaudeDream 是什么？**

ClaudeDream 是一个 **Claude Code 插件**，目标是升级 Claude Code 的记忆系统，使 agent 免于"腐烂"——避免跨会话的上下文漂移与信息丢失，让 agent 始终与用户和项目保持同步。

**核心架构（v0.3.0）：**

```
daily/原始对话日志（hooks自动捕获）
    ↓ /flush
结构化日志条目
    ↓ /compile
knowledge/      编译后的知识文章（concepts / connections / qa）
    ↓ /lint
健康检查报告
    ↓ /query
索引引导检索，无RAG
```

**它做什么：**
- `hooks/` 自动在每次会话结束时把对话捕获进`daily/YYYY-MM-DD.md`
- `/flush` 把原始对话提炼为结构化日志条目
- `/compile` 把日志编译成可查询的知识文章
- `/lint` 检查知识库健康状态（断链、孤页、矛盾等）
- `/query` 通过读index → 选相关文章 → LLM 综合，回答问题

**它不做什么：** 不做对话前端、不做模型推理、不碰 Claude Code CLI 核心流程。

entering plan mode.

initial read or draft). After that, operate on the plan file with targeted
Edits and shell `cp` — never rewrite or re-emit the whole document.
